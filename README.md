Employee Management System (JDBC Version)

​Project Overview

​This is a Java-based Employee Management System that has been upgraded from an in-memory storage (ArrayList) to a persistent database storage using JDBC (Java Database Connectivity).
This ensures that employee records are saved permanently and are not lost when the application is closed.


​Features
​Persistent Storage: Data is stored in a relational database (MySQL/PostgreSQL).
​
CRUD Operations: 
Create: Add new employee records.
​Read: Fetch all employees or search by ID.
​Update: Modify existing employee details.
​Delete: Remove records from the database.
​SQL Integration: Optimized searching and filtering using SQL queries instead of manual loops.
​

Tech Stack
​Language: Java (JDK 8 or higher)
​Database: MySQL / PostgreSQL
​API: JDBC (Java Database Connectivity)
